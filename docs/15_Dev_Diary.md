## 2026-07-24 (금) — 개발 시작

### 오늘 한 것

Android Studio 프로젝트를 만들었다.

패키지명은 com.whybuy.app으로 확정했다.

한 번 정하면 못 바꾼다고 해서

한참 들여다보고 눌렀다.

---

빌드 설정에서 오래 헤맸다.

AGP 9는 Kotlin 플러그인을 이미 갖고 있어서

내가 따로 넣으면 충돌이 났다.

kotlinOptions도 없어졌길래 kotlin { compilerOptions }로 바꿨다.

compileSdk를 36으로 내렸다가

라이브러리들이 37을 요구해서 다시 올렸다.

---

코드는 네 개 만들었다.

WhyBuyApplication

AppDetector

AppWatchService

MainActivity

---

그리고

쿠팡을 열었더니

Logcat에 이게 찍혔다.

앱 전환 감지 >>> com.coupang.mobile

---

GitHub 저장소도 만들었다.

Private으로 했다.

푸시할 때 계정이 두 개라 인증이 꼬였는데

URL에 계정명을 넣으니까 됐다.

---

### 막힌 것

Gradle 설정.

코드보다 빌드 설정에서 시간을 더 썼다.

---

푸시할 때 Repository not found가 계속 떴다.

저장소는 브라우저에서 잘 열리는데 안 됐다.

Private 저장소는 인증이 안 되면

없다고 나온다는 걸 알았다.

---

### 알게 된 것

잘한 선택 같다.

이게 나중에 중요해질 것 같다.
