### Usage Access

# S05. Rule Setting

## 목적

앱별 만남 규칙 설정

---

## 진입 경로

- 앱 선택 직후
- 홈 → 앱 목록 → 앱 선택
- Overlay 종료 시 [만남 조절하기]

---

## 첫 진입

간단 모드부터 보여준다.

---

편이를 얼마나 자주 만나고 싶으세요?

○ 자주 만나고 싶어요 (매번)

● 가끔이면 충분해요 (하루 한 번)

○ 아주 가끔만요 (주 1회)

[직접 설정하기]

---

## 상세 모드

### 빈도

| 값 | 설명 |
|---|---|
| EVERY_TIME | 매번 |
| ONCE_A_DAY | 하루 한 번 |
| MAX_N_PER_DAY | 하루 최대 N번 |
| ONCE_A_WEEK | 주 1회 |
| MIN_INTERVAL | 최소 간격 N분 |

---

### 시간대

| 값 | 설명 |
|---|---|
| ALWAYS | 항상 |
| ONLY_BETWEEN | 이 시간에만 |
| EXCEPT_BETWEEN | 이 시간은 빼고 |

---

자정을 넘는 구간 지원

예) 22:00 ~ 03:00

---

### 요일

| 값 | 설명 |
|---|---|
| EVERYDAY | 매일 |
| WEEKDAY | 평일만 |
| WEEKEND | 주말만 |
| CUSTOM | 직접 선택 |

---

### 잠시 멈춤

- 오늘 하루
- 이번 주
- 날짜 지정
- 이 앱 끄기

---

## 기본값
