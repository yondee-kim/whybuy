# 앱별 만남 규칙

## 왜 필요한가

WHYBUY는

사용자의 생활을 방해하면 안 된다.

매번 나타나는 편이는

처음에는 반갑지만

나중에는 피곤한 존재가 된다.

피곤해진 순간

사용자는 앱을 지운다.

그러므로

편이가 언제 찾아올지는

WHYBUY가 정하지 않는다.

사용자가 정한다.

---

## 원칙

빈도는

서비스가 결정하지 않는다.

사용자가 결정한다.

앱마다

의미가 다르다.

쿠팡은 생필품일 수 있고,

무신사는 나를 위한 소비일 수 있고,

배달앱은 늦은 밤의 습관일 수 있다.

그러므로

규칙은

앱마다 따로 설정한다.

---

## 규칙 구성 요소

사용자는

아래 요소를 조합해

### 1. 빈도

- 매번
- 하루 한 번
- 하루 최대 N번
- 주 1회
- 실행 간격 N분 이상일 때만

---

### 2. 시간대

- 항상
- 특정 시간대만
  - 예) 22:00 ~ 03:00
- 특정 시간대 제외
  - 예) 업무 시간 제외

---

### 3. 요일

- 매일
- 평일만
- 주말만
- 요일 직접 선택

---

### 4. 잠시 멈춤

- 오늘 하루 쉬기
- 이번 주 쉬기
- 이 앱만 잠시 끄기

# User Flow 핵심

WHYBUY는

사용자가

앱을 사용한다고 느끼면 안 된다.

쇼핑하다가

잠깐

편이를 만나는 정도가

가장 이상적인 경험이다.

그리고

그 만남의 빈도는

WHYBUY가 아니라

사용자가 정한다.

사용자가 편이를 부담스러워하는 순간

WHYBUY는 사라진다.

오래 곁에 있으려면

먼저 물러설 줄 알아야 한다.
