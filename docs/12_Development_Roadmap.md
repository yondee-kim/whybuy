# WHYBUY Development Roadmap

Version 1.0

목표 출시일: 3개월 후

---

# 전제

## 개발 환경

- 1인 개발
- 본업 + 육아 병행
- 실제 개발 가능 시간: 주 10~15시간

---

## 그래서

이 로드맵은

"할 수 있는 것"이 아니라

"버려도 되는 것"을 정하는 문서이다.

---

## 최우선 원칙

편이가

쇼핑앱 위에 나타나는 것.

이것 하나만 되면

나머지는 전부 나중에 해도 된다.

---

# 전체 일정

| 월 | 기간 | 목표 |

| M1 | 1~4주 | 핵심 기술 검증 + 감지/Overlay |
| M2 | 5~8주 | 앱 완성 (로컬 전용) |

- 앱 감지

말투가 WHYBUY이다.

# 위험 요소

| 위험 | 확률 | 영향 | 대응 |
|---|---|---|---|
| Overlay + Compose 구현 난이도 | 높음 | 치명 | W2에 집중, 안 되면 XML View로 |
| specialUse FGS 심사 거절 | 중간 | 치명 | 사유서, 데모 영상, 재제출 |
| 제조사 절전으로 감지 실패 | 높음 | 큼 | 안내 가이드, 완벽 대응 포기 |
| 편이 일러스트 지연 | 중간 | 중간 | 임시 도형으로 개발 진행 |
| 개발 시간 부족 | 높음 | 큼 | 버릴 것 목록대로 축소 |
| 심사 반려 반복 | 중간 | 큼 | 12주차를 여유 주간으로 확보 |
